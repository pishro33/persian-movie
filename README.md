# Persian Movie

A responsive movie discovery web app for Persian and Iranian cinema.

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Current implementation
- Dark navy responsive design
- Homepage movie grid
- Search and genre filters
- Mobile hamburger navigation
- Dynamic movie detail page with a player placeholder

Movie data and poster treatments are placeholders. No third-party streams or copyrighted media are copied. Connect only authorized artwork, metadata, and playback sources.
